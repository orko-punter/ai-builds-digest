# AI Builds digest — how it runs
- Main digest: cloud routine "AI Builds Daily digest" (Opus 5.5), daily 08:00 UTC.
  Runs on Anthropic's servers — Mac/app can be off. Manage: https://claude.ai/code/routines/trig_01Tb6f6J9vgQEbd9g4wjX173
  Dedupes by searching your Gmail for past digests. Connector: Gmail only.
- FT add-on: local scheduled task "FT AI builds add-on" (~08:43 London), needs the Claude app + Chrome open.
  Sends nothing when there's no FT story or Chrome isn't connected. Prompt backup: instructions-backup.md
